# 지역화된 제목 없는 노트 파일명 디자인

- 날짜: 2026-08-01
- 상태: 승인됨
- 범위: Note Browser의 범용 파일 저장에서 제목 없는 노트에 제안하는 기본 파일명

## 1. 배경

범용 파일 저장 창은 현재 파일명 제안 시 사용자 지정 제목과 적용된 캘린더 제목을 우선 사용한다. 둘 다 없으면 전사문의 첫 줄을 사용하고, 전사문도 없을 때만 고정된 영문 `yyyy-MM-dd HH-mm` 날짜를 사용한다.

전사 첫 줄은 노트 제목이 아니며, 언어·내용에 따라 길이가 달라져 파일명 기본값으로 일관되지 않다. 고정 영문 날짜 형식도 앱의 지역화 흐름과 맞지 않는다.

## 2. 목표

- 사용자 지정 제목과 적용된 캘린더 제목이 모두 없는 노트는 노트 시각으로 만든 임시 제목을 기본 파일명으로 사용한다.
- 기본 파일명은 현재 시스템 locale의 날짜·시간 표기를 따른다.
- 한국어 예시는 `2026년 7월 24일 오전 1:45`이다.
- 기본 이름은 전사 텍스트 유무와 내용에 영향을 받지 않는다.
- 전사 텍스트와 녹음 파일을 함께 저장해도 공통 기본 이름을 사용한다.

## 3. 비목표

- 노트 목록과 상세 화면의 제목 표시 규칙을 바꾸지 않는다.
- 기존 노트 기록에 임시 제목을 저장하거나 마이그레이션하지 않는다.
- 사용자가 저장 창에서 수정한 파일명을 자동으로 덮어쓰지 않는다.
- 파일 확장자, 충돌 확인, 덮어쓰기 확인, 원본 복사 동작을 변경하지 않는다.

## 4. 선택한 방향

다음 선택지를 검토했다.

1. 파일 저장 이름 계산부에서만 locale 기반 날짜 제목을 계산한다.
2. `NoteTitleResolver`를 확장해 목록 제목과 파일명을 동일한 날짜 제목으로 통합한다.
3. 임시 제목 문자열을 기록 데이터에 영구 저장한다.

첫 번째 방향을 선택한다. 이번 요구는 다운로드 기본값에 한정되며, 현재 노트 목록은 전사 첫 줄과 상태별 제목을 의도적으로 사용한다. 기록 모델을 바꾸지 않으므로 기존 데이터의 표시·호환성에도 영향을 주지 않는다.

## 5. 설계

### 5.1 이름 결정 우선순위

`NoteFileExportNaming.suggestedBaseName`은 다음 순서로 제안 이름을 결정한다.

1. 공백만 있는 값을 제외한 사용자 지정 제목
2. 적용된 캘린더 제목
3. 노트의 `timestamp`를 현재 locale로 형식화한 날짜·시간 임시 제목

전사문의 첫 줄을 사용하는 단계와 고정 `yyyy-MM-dd HH-mm` fallback은 제거한다.

### 5.2 지역화된 날짜·시간 형식

날짜·시간은 Foundation의 locale 인식 `Date.FormatStyle`을 사용한다.

- 기본 locale은 `.current`이다.
- 테스트에서는 `ko_KR` 및 `en_US` locale을 명시해 결과를 결정적으로 검증한다.
- 한국어에서는 긴 날짜와 축약 시간을 조합해 `2026년 7월 24일 오전 1:45` 형태를 생성한다.
- 영어 등 다른 locale에서는 해당 locale의 일반적인 긴 날짜·시간 형식을 사용한다.

날짜 계산은 저장 시점이 아니라 노트에 이미 기록된 `timestamp`를 사용한다. 따라서 같은 노트를 다시 저장해도 동일한 시각을 기본값으로 제안한다.

### 5.3 macOS 파일명 정리

기존 파일명 정리 로직은 `:`를 무효 문자로 판단해 시간의 `1:45`를 `1-45`로 변경한다. 요구한 기본 이름을 그대로 유지하기 위해 `:`는 허용한다.

앱의 대상 플랫폼은 macOS이며, 최신 macOS 파일 시스템에서 `:`는 파일명에 사용할 수 있다. `/`, 역슬래시, 제어 문자 등 경로를 깨거나 이식성을 해치는 기존 무효 문자는 계속 정리한다. 사용자·캘린더 제목의 다른 정리 규칙과 fallback 처리도 유지한다.

### 5.4 흐름과 오류 처리

Note Browser는 저장 창을 열 때 현재와 같이 사용자 지정 제목과 적용된 캘린더 제목을 전달한다. 제목이 없으면 `NoteFileExportNaming`이 노트 `timestamp`에서 locale 기반 기본 이름을 만들고, 저장 창의 파일명 입력란과 미리보기에 표시한다.

저장 대상, 확장자 선택, 목적지 권한, 기존 파일 충돌, 원자적 복사, 부분 실패 메시지는 기존 `NoteFileExporter` 흐름을 그대로 사용한다. 날짜 이름 자체는 유효한 파일명이므로 별도 오류 경로를 추가하지 않는다.

## 6. 테스트

`NoteFileExportTests`에 다음을 추가한다.

- 사용자 지정 제목이 있으면 날짜 이름보다 우선하는지 검증한다.
- 제목과 캘린더 제목이 없는 경우 `ko_KR` locale에서 `2026년 7월 24일 오전 1:45`를 생성하는지 검증한다.
- 같은 시각이 `en_US` locale에서는 영어 날짜·시간 형식으로 생성되는지 검증한다.
- 로컬화된 날짜 이름을 요청에 넣었을 때 실제 전사·녹음 파일명이 `:`를 보존하는지 검증한다.

기존 전체 `make test`로 파일 저장, 지역화 리소스, 노트 제목·목록 표시 관련 회귀를 함께 확인한다.
